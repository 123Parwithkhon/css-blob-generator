🎨 CSS Blob Generator
An interactive web application for generating organic CSS shapes (blobs) with customizable dimensions, complex border-radius curves, and a one-click CSS code copying feature.

🔗 Live Demo: https://123parwithkhon.github.io/css-blob-generator/

🚀 Features
- Interactive sliders and number inputs for real-time shaping and dimension adjustments[cite: 21, 22, 23].
- Generates complex multi-value CSS border-radius properties dynamically[cite: 21].
- One-click CSS code copying utility with instant visual feedback[cite: 21].
- Clean card-based interface styled with Google Fonts (Roboto Mono) and vibrant gradients[cite: 22, 23].

🛠 Technologies Used
- HTML5 (Semantic wrapper structures, range sliders, number input fields)[cite: 23]
- CSS3 (Flexbox/Grid layout, absolute centering, custom gradients, box-shadows)[cite: 22]
- JavaScript (Dynamic DOM styling, string template literals, clipboard copy commands)[cite: 21]

💻 How to Run
1. Clone or download this repository:
   git clone https://github.com/123Parwithkhon/css-blob-generator.git
2. Navigate to the project folder:
   cd css-blob-generator
3. Open index.html in any web browser.

🎨 Генератор CSS блобов
Интерактивное веб-приложение для создания органических CSS-фигур (блобов) с настраиваемыми размерами, сложными кривыми border-radius и функцией копирования готового кода в один клик.

🔗 Демо: https://123parwithkhon.github.io/css-blob-generator/

🚀 Особенности
- Интерактивные слайдеры и числовые поля для изменения формы и размеров в реальном времени[cite: 21, 22, 23].
- Динамическая генерация сложных многозначных свойств CSS border-radius[cite: 21].
- Утилита копирования готового CSS-кода в буфер обмена в один клик с мгновенным уведомлением[cite: 21].
- Аккуратный интерфейс карточки со стилизацией шрифтом Roboto Mono и градиентами[cite: 22, 23].

🛠 Используемые технологии
- HTML5 (семантическая структура, ползунки range, числовые поля number)[cite: 23]
- CSS3 (флексбоксы и грид-сетки, абсолютное центрирование, градиенты, тени)[cite: 22]
- JavaScript (динамическое изменение стилей в DOM, шаблонные строки, команды копирования)[cite: 21]

💻 Как запустить
1. Клонируйте или скачайте этот репозиторий:
   git clone https://github.com/123Parwithkhon/css-blob-generator.git
2. Перейдите в папку проекта:
   cd css-blob-generator
3. Откройте файл index.html в любом веб-браузере.
